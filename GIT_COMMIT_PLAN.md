# Suggested practice commit history

If you want a realistic development history, do not make 12 fake empty commits. Make the commits reflect actual feature groups.

1. `git init` / project foundation
2. `Add EF Core Identity DbContext and database models`
3. `Configure Identity roles and JWT authentication`
4. `Implement college registration and approval workflow`
5. `Implement placement officer registration and approval`
6. `Implement company and HR approval workflow`
7. `Implement student enrollment and Excel import`
8. `Implement jobs and eligibility rules`
9. `Implement job applications and status history`
10. `Implement recruitment drives and interview scheduling`
11. `Add global exception handling and authorization checks`
12. `Add placement reports, Swagger and documentation`

To create these honestly, copy/add the relevant feature folders in the order above and commit after each phase. If you already have the complete project and only need a practice history, use the same order as a guide rather than fabricating timestamps or pretending code was developed earlier.
